# Recipe search: new sources and creator support links

Research date: 2026-11-08. No repo was changed.

How this was checked: requests went out from a cloud sandbox with the crawler's real user agent, `Mozilla/5.0 (compatible; RecipeSearchBot/0.1; +https://kylepace.net)` (from `crawler/crawl.mjs`). This setup gets the same HTTP 403 from Just One Cookbook and Maangchi that GitHub Actions got on 2026-11-02, so a 200 here is a decent sign a site will also answer GitHub Actions. It isn't a guarantee, since the IP ranges differ. For each site I read robots.txt, read the sitemap index and counted URLs in the post sitemap(s), fetched recipe pages and looked for `"@type":"Recipe"` JSON-LD (or `itemtype="https://schema.org/Recipe"` microdata, which is what `crawler/lib/extract.mjs` needs), and searched the terms, privacy and disclosure pages for clauses on automated access, storage and linking.

Counts are URLs in the post sitemap, not confirmed recipes. Some posts are articles with no recipe card, and the crawler already skips those.

## Notes

1. **User-agent contact link.** `crawler/crawl.mjs` sends `+https://kylepace.net`. The brief says the contact page is https://kylepace.dev/recipe-search/. Consider pointing the UA at the recipe-search page so site owners land somewhere that explains the bot.
2. **Sitemaps not listed in robots.txt:** Korean Bapsang, Viet World Kitchen, Swasthi's and Cooking with Ayeh. All of them still serve `/sitemap_index.xml`, so set `sitemap:` in `sources.yaml` the way Woks of Life already does.
3. **Suggested `default_cuisine` values,** since cuisine is often missing: Korean Bapsang (Korean), Maureen Abood (Lebanese), Made With Lau (Cantonese or Chinese), Hungry Huy (Vietnamese), Viet World Kitchen (Vietnamese).
4. **Permission asks worth sending,** in order of fit: Red House Spice (Chinese, strong fit), then Sally's Baking Addiction and The Mediterranean Dish (both forbid deep links, which a link-out index can't avoid). Serious Eats is already link-out only. These three could go link-out only too: a "search this site" link needs no crawling and no stored data. But Sally's and The Mediterranean Dish ban linking to anything but their home pages, so even search links technically break their terms.
5. **Seonkyoung guard.** Several of her pages output a sidebar recipe's JSON-LD ("Spicy Enoki Mushroom"), not the page's own. Without a check that the Recipe name roughly matches the page title, the index would show wrong titles and ingredients under her links.
6. **Swasthi's empty sitemap.** Her post sitemaps return 200 with a 0-byte body from the Sucuri cache. That can be temporary. If it lasts, the crawler finds nothing, because it only reads sitemaps.
7. **Photos.** For any new site with photos, add its image host to `.agents/allowed-hosts.txt` as the image rule says.
8. **URLs checked,** beyond those in the tables: robots.txt and the home page for every site in Table 1; the post sitemaps listed above; recipe pages including https://redhousespice.com/scissor-cut-noodles/, https://omnivorescookbook.com/tang-yuan/, https://www.madewithlau.com/recipes/chow-mein, https://japan.recipetineats.com/bento-box-chicken-karaage-bento/, https://www.koreanbapsang.com/flank-steak-bulgogi/, https://www.vietworldkitchen.com/blog/2026/11/vietnamese-grilled-eggplant-with-garlicky-green-onion-sizzle.html, https://www.hungryhuy.com/japanese-milk-bread/, https://www.indianhealthyrecipes.com/chicken-biryani-recipe/, https://patijinich.com/pumpkin_and_ancho_chile_mole/, https://maureenabood.com/kibbeh-nayeh-the-raw-truth/, https://cookingwithayeh.com/beetroot-hummus/, https://www.recipetineats.com/pea-and-ham-soup/, https://seonkyounglongest.com/spicy-pork/, https://seonkyounglongest.com/2012-japchae/, https://www.themediterraneandish.com/tuna-couscous-salad-recipe/, https://sallysbakingaddiction.com/homemade-brioche/, https://www.chinasichuanfood.com/mapo-tofu/, https://www.rickbayless.com/recipe/marketplace-tacos/, https://blog.themalamarket.com/chengdu-noodles-above-and-beyond-dan-dan-mian/; and terms pages https://redhousespice.com/terms/, https://cookingwithayeh.com/terms, https://patijinich.com/terms, https://www.themediterraneandish.com/terms-of-use/, https://www.recipetineats.com/policy-use-of-recipes-images/, https://sallysbakingaddiction.com/disclosure-policy/ and https://www.indianhealthyrecipes.com/terms/.
